## Aplicación móvil para pedidos de café

Una aplicación moderna desarrollada en React Native con Expo para realizar pedidos de café de manera intuitiva.

### Características

-  Navegación fluida entre pantallas
-  Sistema de carrito de compras
-  Lista de favoritos personalizada  
-  Proceso de entrega integrado
-  100% cobertura de pruebas en Context
-  Integración continua con GitHub Actions

### Testing

```bash
npm test              # Ejecutar pruebas
npm run test:coverage # Pruebas con cobertura
npm run test:ci       # Modo CI/CD
```

### Desarrollo

```bash
npm start            # Iniciar aplicación
npm run android      # Ejecutar en Android
npm run ios          # Ejecutar en iOS
npm run web          # Ejecutar en navegador
```
